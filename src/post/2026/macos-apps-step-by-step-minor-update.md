The book is available for purchase or update at [Gumroad][2].

If you bought a previous edition of "macOS by Tutorials" or "macOS Apps Step by Step" from me via Gumroad, version 4.1 is a free update that you can download from your [Gumroad library][7].

If you bought the first edition of macOS by Tutorials from either Kodeco or Amazon, please [email me][3] for a 50% discount code.

[![Book cover][i1]][1]

Click the image for more details, and if you’d like to check out the start of the book including the table of contents and the first chapter, you can read it online at [macOS Apps Step by Step Sample][4].

The only change in version 4.1 is adapting to the new structure of the API used in the first app: On This Day. Most of the changes are in chapter 1, but the code for the app has been updated throughout section 1 of the book.

If you already own the book and have enjoyed it or found it useful, I'd really appreciate it if you could leave a rating or review at the book's page in your [Gumroad library][7].

There will be a more significant update when I work out what changes macOS 27 and Xcode 27 bring, but in the meantime, this fix makes sure that the app still works.
